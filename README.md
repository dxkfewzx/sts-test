# ระบบตรวจสอบสต็อกอุปกรณ์ (Flask on Vercel) พร้อมระบบล็อกอินและการจัดการผู้ใช้

ระบบตรวจสอบสต็อกอุปกรณ์แบบเต็มรูปแบบที่สร้างด้วย Flask และพร้อมสำหรับการติดตั้งบน Vercel โดยใช้ Python preset ประกอบด้วยระบบล็อกอิน การจัดการวัสดุและหมายเลขซีเรียล รวมถึงความสามารถในการเพิ่มผู้ใช้จากหลังบ้าน

## คุณสมบัติ
- ดูรายการอุปกรณ์ทั้งหมด
- เพิ่มอุปกรณ์ใหม่
- แก้ไขข้อมูลอุปกรณ์
- ลบอุปกรณ์
- จัดการหมายเลขซีเรียล (SN) ของแต่ละรายการ
- ระบบล็อกอินด้วย Flask-Login
- เพิ่ม/แก้ไข/ลบผู้ใช้ (เฉพาะแอดมิน)
- เก็บข้อมูลในฐานข้อมูล SQLite (ใน `/tmp` บน Vercel - เหมาะสำหรับการทดสอบ)
- รองรับมือถือ (sidebar พับได้)
- หน้าตาเหมือนระบบเดิม (ใช้ Bootstrap 5, ฟอนต์ Prompt, ไอคอน Bootstrap)

## วิธีการติดตั้งบน Vercel

### ขั้นตอนที่ 1: เตรียมความพร้อม
1. ติดตั้ง Node.js (หากยังไม่มี) – Vercel CLI ต้องการ Node.js v14+
   ```bash
   node -v
   ```
2. ติดตั้ง Vercel CLI ทั่วโลก
   ```bash
   npm i -g vercel
   ```
3. เข้าสู่ระบบ Vercel
   ```bash
   vercel login
   ```

### ขั้นตอนที่ 2: ติดตั้งและเผยแพร่
1. ไปที่โฟลเดอร์โปรเจ็ค
   ```bash
   cd /home/adminx/sts-test
   ```
2. รันคำสั่ง deploy
   ```bash
   vercel
   ```
3. ตอบคำถามตามที่ระบบถาม
   - **Set up and deploy “sts-test”?** → `Y` (หรือกด Enter)
   - **Which scope do you want to deploy to?** → เลือกบัญชีส่วนตัวหรือทีมของคุณ
   - **Link to existing project?** → `N` (สร้างโปรเจ็คใหม่)
   - **What’s your project name?** → พิมพ์ชื่อที่ต้องการบน Vercel (เช่น `inventory-system-with-login`) หรือกด Enter เพื่อใช้ชื่อโฟลเดอร์ `sts-test`
   - **In which directory is your code located?** → `.` (จุดเดียว)
   - **Want to override the settings?** → `N` (ใช้การตั้งค่าจาก `vercel.json` ที่เราเตรียมไว้)

### ขั้นตอนที่ 3: รอการติดตั้งเสร็จสิ้น
Vercel จะ:
- ตรวจจับว่าเป็นโปรเจ็ค Python จาก `vercel.json`
- ติดตั้ง dependencies จาก `requirements.txt` (Flask, Flask-Login ฯลฯ)
- สร้าง serverless function จาก `api/index.py`
- ให้ URL ที่คล้ายกับ: `https://inventory-system-with-login.vercel.app`

### ขั้นตอนที่ 4: เข้าใช้งาน
เปิดเบราว์เซอร์ไปที่ URL ที่ได้รับ คุณจะเห็นหน้าเข้าสู่ระบบ (`/login`)  
ใช้บัญชีเริ่มต้นที่ระบบสร้างให้อัตโนมัติ:
- **ชื่อผู้ใช้**: `admin`
- **รหัสผ่าน**: `admin123`

หลังจากล็อกอินสำเร็จ คุณจะถูกเปลี่ยนเส้นทางไปยังหน้าดashboard และสามารถเริ่มใช้งานระบบได้ทันที

## โครงสร้างไฟล์
```
sts-test/
├── api/
│   ├── index.py                 ← จุดเข้า Flask (Vercel Serverless Function)
│   ├── requirements.txt         ← รายการ dependencies (Flask, Flask-Login, Werkzeug)
│   └── templates/
│        ├─ dashboard.html       ← หน้าดashboard หลัก (แสดงสรุปสถานะ)
│        ├─ login.html           ← หน้าเข้าสู่ระบบ
│        ├─ inventory_list.html  ← รายการวัสดุทั้งหมด
│        ├─ details.html         ← รายละเอียดหมายเลขซีเรียล (SN) ของวัสดุ
│        ├─ add_item.html        ← ฟอร์มเพิ่มวัสดุใหม่
│        ├─ edit_item.html       ← ฟอร์มแก้ไขวัสดุ
│        ├─ add_user.html        ← ฟอร์มเพิ่มผู้ใช้ใหม่ (เฉพาะแอดมิน)
│        └─ ... (สามารถเพิ่ม template อื่น ๆ ได้ตามต้องการ)
├── vercel.json                  ← ตั้งค่าให้ใช้ @vercel/python Builder
├── workflow.md                  ← ขั้นตอนการทำงาน (workflow) สำหรับโปรเจกต์นี้
└── README.md                    ← ไฟล์นี้
```

## หมายเหตุสำคัญ
- ฐานข้อมูล SQLite จะถูกสร้างขึ้นใน `/tmp/inventory.db` ซึ่งเป็นไดเรกทอรีที่เขียนได้บน Vercel แต่ข้อมูลจะหายไปเมื่อฟังก์ชันถูกรีไซเคิล (โดยปกติทุก ๆ ชั่วโมง หรือเมื่อไม่มีการใช้งาน) – เหมาะสำหรับการทดสอบหรือการใช้งานชั่วคราว
- หากต้องการเก็บข้อมูลถาวร ให้พิจารณาใช้ฐานข้อมูลภายนอก เช่น Vercel Postgres, Supabase หรือบริการอื่น ๆ และแก้ไขสตริงเชื่อมต่อใน `api/index.py`
- ในการผลิตควรตั้งค่าตัวแปรสิ่งแวดล้อม `SECRET_KEY` ในแดชบอร์ด Vercel เพื่อความปลอดภัย (แทนการใช้ค่าเริ่มต้น 'dev-secret-key-change-in-production')

## การอัปเดตในอนาคต
หลังจากแก้ไขไฟล์ใด ๆ ให้รัน
```bash
vercel --prod
```
เพื่ออัปเดตการผลิต หรือรัน `vercel` เพื่อสร้าง preview ก่อน
